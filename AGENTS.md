
Стек: Vite, React, TypeScript (strict), MobX, mobx-react-lite, Vitest, Playwright, zod. Серверная часть: одна serverless-функция в /api.

Структура: /src/domain, /src/services (svg, layout, ai), /src/stores, /src/ui, /scripts, /api.

Правила проекта:
- ИИ никогда не генерирует графику, он только выбирает объекты из каталога и роли (main/bg).
- Результат всегда векторный SVG, без <image>, foreignObject и глобальных <style>.
- Пропорции объектов не меняются: масштаб только одним числом.
- Цвета объектов нельзя использовать в фоновых объектах, цвета фонов можно использовать в объектах.
- Доменная логика пишется чистыми функциями без React и MobX и покрывается тестами.
- Команды: dev, build, test, lint.

Кратко опиши эти правила и команды, ничего больше не реализуй.
